Retail Sales and Growth Analysis Dashboard

📊 Project Overview

The Retail Sales and Growth Analysis Dashboard is a data analytics project developed using Microsoft Power BI and Excel to analyze retail sales performance, identify business trends, and monitor growth opportunities.

The project combines six datasets to provide a consolidated view of retail business performance. Data was cleaned, transformed, and prepared for analysis using Power Query. Relationships were established between datasets using common columns, and DAX calculations were implemented to generate meaningful insights.

The dashboard helps understand sales performance, track growth trends, and support data-driven business decisions through interactive visualizations.

🎯 Project Objectives

- Analyze overall retail sales performance.
- Understand sales and growth trends.
- Combine multiple datasets for comprehensive analysis.
- Identify key business performance indicators.
- Track important sales metrics using interactive dashboards.
- Present meaningful insights through data visualization.
- Support business decision-making using data-driven insights.
